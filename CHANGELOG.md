# Changelog

## 0.1.1 (2026-10-18)

Rows in the fights, judge-round, and crosswalk files are now sorted from the most recent event to the oldest, and within an event from the main event down. Added the card_position column to the fights file. No other values changed.

## 0.1.0 (2026-10-18)

First release: 6,743 fights from 2013-02-16 through 2026-10-10, 29,937 judge-rounds, and a codebook.
